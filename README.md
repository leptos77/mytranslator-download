# 쉽게번역 내려받기

영어를 복사하거나 캡처한 뒤 메뉴 막대(윈도우는 작업 표시줄) 아이콘을 누르면, 문장은 번역하고 단어는 사전 카드로 보여 주는 앱이다. 소개: https://mytranslator.ilsoft.net

설치 파일은 [Releases](https://github.com/leptos77/mytranslator-download/releases)에만 있다. 이 저장소에는 코드가 없다.

## 항상 최신판 주소

| | 주소 |
|---|---|
| 맥 | `https://github.com/leptos77/mytranslator-download/releases/latest/download/MyTranslator-mac.dmg` |
| 윈도우 | `https://github.com/leptos77/mytranslator-download/releases/latest/download/MyTranslator-windows-setup.exe` |

## 처음 열 때

지인 배포용이라 Apple·Microsoft 서명을 받지 않았다. 처음 한 번 경고가 뜬다.

- 맥: 앱을 열면 "열 수 없음"이 뜬다 → 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기".
- 윈도우: "Windows의 PC 보호"가 뜬다 → "추가 정보" → "실행".

말 번역(🎤·🔊)을 처음 누르면 받아쓰기 모델(547MB)을 한 번 받는다. 모델은 [ilsoft-models](https://github.com/leptos77/ilsoft-models)에 있다.
